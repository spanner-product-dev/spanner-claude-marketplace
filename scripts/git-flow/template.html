what the labels and filters mean

the type and area of a pull request are worked out by the build from its branch name, title and files, not typed by a person, so treat them as a good guess. counts are pull requests.
what this page is: a read-only picture of the git and pull request history of spanner-claude-marketplace, the source of truth for Spanner's Claude skills and plugins, built from GitHub and the full git log on __ASOF__. merging to main does not ship a skill: it reaches people when the org Skills Library copy is replaced from dist/org-settings, or when the plugin is updated. design reference: SpannerOS design system + Torque (dark default; dark · light · system).
read before you rely on it: GitHub does not keep push times in what I could reach, so "pushed" here is the last commit on the branch, which is the closest honest proxy. "opened" and "merged" times come from GitHub itself. "first commit" and "last commit" are author times and can precede the push. A PR that landed without a merge commit (squashed) shows no commit list. "unmerged work" means the branch tip is not an ancestor of main, so a squash-merged branch could be mislabeled; the branches flagged here are worth a look either way.
